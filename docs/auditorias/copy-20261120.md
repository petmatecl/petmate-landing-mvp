## Decisiones pendientes del PO

### D1. Fixes C-1 a C-5 pre-campañas

**Pregunta**: ¿autorizás pasada de copy fix (~1h) para desactivar los 5 copys "pre-launch" residuales?

**Recomendación**: sí. Es el fix más cost-effective del día. Un visitante nuevo ve "estamos construyendo" + "sé el primero" y asume que el sitio no está listo.

**Impacto si no se decide**: default = copy inconsistente con la realidad operativa.

### D2. Rewording C-5 — "Sin comisión por conectar" vs mantener la promesa

**Pregunta**: ¿la promesa "Sin comisión" es permanente (no vamos a cobrar nunca) o es solo mientras no haya pagos in-platform?

**Recomendación**: hoy no hay pagos. Si el PO decide cobrar en el futuro, el copy actual se vuelve engañoso. Mejor: "Sin comisión por conectar" (promesa específica al acto de match, no al servicio completo).

**Impacto si no se decide**: default = dejar como está hasta que haya pagos.

### D3. Taxonomía "solicitud" vs "reserva" en emails

**Pregunta**: ¿el pass de 30 min para cerrar E-1 a E-4 se agenda pre-campañas o se deja para la primera semana post-activación?

**Recomendación**: pre-campañas. El copy actual de los 4 emails confunde "agendamiento" (admin) con "reserva" (user-facing).

**Impacto si no se decide**: default = deuda de taxonomía documentada.

### D4. Voice & tone guide formal

**Pregunta**: ¿valide armar un doc `docs/voice-tone.md` con convenciones (español chileno tuteo, sin voseo, nivel formal, cuándo cálido, etc.)?

**Recomendación**: media prioridad. Útil cuando crezca el equipo o cuando trabajemos con copywriter externo. Hoy el tono es uniforme suficiente.

**Impacto si no se decide**: default = tono por heurística del auditor/PO.

### D5. ErrorBoundary y 500.tsx copy mejorado

**Pregunta**: ¿cambiamos "Algo salió mal" a algo más instructivo tipo "Ocurrió un problema. Recarga la página o vuelve al inicio."?

**Recomendación**: sí, 10 min. Ayuda al user a recuperarse sin cerrar la pestaña.

**Impacto si no se decide**: default = copy actual.
